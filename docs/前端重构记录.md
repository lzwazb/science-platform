# 前端重构记录

> 依据 oil-ui 的流程执行：产品事实 → 方向 → 素材 → 实现 → 真实画面评审。
> 技术栈、接口契约、权限规则、路由名称一律不动，只重建**内容呈现层**。

## 一、方向

**让内容成为视觉主角。**

原来的封面是抽象几何 SVG（蓝底十字、绿底同心圆、紫底六边形），三张并排风格各异，
看着像临时占位图。对科普平台来说这是浪费——星系、染色体、病毒、晶体本身就很有视觉说服力，
却被抽象图形挡住了。

所以这一轮的核心动作：**用真实科学影像替换抽象插画，用学科色建立辨识度，用密度和排版拉出层级。**

## 四、页面改动

### 知识库（`KnowledgeListView.vue`）

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 网格 | 3 列 | **4 列**（1440 下每张 285px） |
| hero 高度 | 约 180px | 约 150px（padding 30/32 → 22/26，标题 26 → 21px） |
| 分类标签 | 统一蓝色 `el-tag` | 学科色竖线 + 学科色文字 |
| 卡片 | 1px 边框 + 阴影 | 极淡边框 + 悬停浮起 3px + 封面放大 1.045 |
| 标题 | 15px / 两行截断 | 13.5px + `text-wrap: balance` |

**为什么要 balance**：标题 19 字、每行约 17 字，自然折行会出现「…长期记 / 忆」这种孤字。
均衡两行长度后读起来顺，虽仍可能在词中断开，但比孤字好。

### 首页（`HomeView.vue`）

- hero 从 40/40/36 内边距压到 30/32/28，标题 32 → 30px，整体少约 70px
- 文章区固定 **3 列**（原来是 `auto-fill minmax(320px)`，1440 下会排 3 列但不稳定）
- 封面比例 16:7 → **16:9**，与全站统一
- 分类标签改学科色

**首页 3 列、知识库 4 列是刻意的**：首页是门户展示，卡片更大更铺张；
知识库是工具页面，追求一屏看到更多。两个页面因此有节奏差异。

### 文章详情（`ArticleDetailView.vue`）

- 顶部加 3px 学科色渐变指示线
- 分类标签从蓝色 `el-tag` 改为学科色竖线样式
- 阅读宽度继续用 `--sp-container-reading`（900px）

### 作品广场（`WorkListView.vue`）

- 网格 3 列 → **4 列**，断点与知识库一致

**作品封面保留原有的几何插画**。这不是偷懒：文章是「真实世界」，作品是「创作者再加工」，
两者用不同的视觉语言反而能区分开。而且现有 3 张作品封面本身风格统一（深色底 + 细线几何）。

## 五、实测中修掉的问题

**1. 标题孤字**

初版 14px、自然折行，出现「疫苗为什么有效：一次预演换来长期记 / 忆」，第二行只有一个「忆」。
改 `text-wrap: balance` + 字号降到 13.5px 后，8 条标题里 6 条能单行放下。

**2. 学科色标签不生效**

`--cat` 变量已经传到卡片元素上，但 `.article-card__category` 的颜色仍是品牌蓝。
原因是旧规则里 `color: var(--sp-primary-dark)` 写在后面覆盖了。重写整条规则后生效：

```
健康医学    → rgb(224, 100, 92)
地球与环境  → rgb(63, 158, 90)
信息技术    → rgb(139, 92, 246)
```

**3. 详情页指示线不显示**

我一开始选的是 `.article-card::before`，但详情页的容器 class 是 `.article-shell`。
改正后实测：`height: 3px`、渐变从 `rgb(21,160,129)` 起（生命科学青绿）。

**4. 卡片在浅底上「漂浮」**

去掉边框只用阴影后，卡片边界不清晰。补一条 `rgba(24,44,68,0.06)` 的边框压住。

**未做**：

- 首页文章卡片与知识库卡片目前是两套类名（`.article-card` / `.kb-card`），样式相近但重复。
  下批可以考虑抽成共享组件 `ArticleCard.vue`，减少两处同步维护的成本。

  要彻底解决需要后端在分类表加 `code` 字段，属于接口改动，本轮不碰。
