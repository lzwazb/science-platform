## 一、项目是什么

**基于 Spring Boot + Vue 的科普知识共创与创意传播平台**（本科毕业设计）。

核心业务：读者读科普文章 → 发现错误可提交纠错 → 采纳后文章升版本 → 创作者把知识做成图文/漫画/短视频 → 审核通过后公开 → 还能参加主题活动拿奖。

**技术栈**

| 层 | 技术 |
| --- | --- |
| 后端 | Spring Boot 3.5.16 · Java 21 · MyBatis-Plus 3.5.18.1 · MySQL 8.0.42 · Spring Security + JWT |
| 前端 | Vue 3.5 · Vite 8.3 · Vue Router 5.4 · Pinia 4.1 · Element Plus 2.14 |
| 构建 | Maven 3.9.9 · Node（前端） |

**目录**

├── database\                  schema.sql / seed.sql

## 三、改动后必须做的验证

**这一节是踩过坑的，不要省略。**

### 改后端

```
1. mvn -s ... package        ← 关键：只跑 mvn test 不算数
2. 杀掉旧 java 进程，启动新 jar
3. 用 curl 调接口确认
```

> **血泪教训**：某次删了一张表、跑完 `mvn test` 全绿就宣布"修好了"，
> 但没重新 package，线上跑的还是旧字节码，页面直接 500。
> `mvn test` 通过只说明源码能跑，不说明运行中的那份能跑。

### 改前端

```powershell
npm run build                      # 必须绿
curl.exe -s -o NUL -w "%{http_code}" http://localhost:5173/works   # 页面 200
```

前端**没有** lint / 单测脚本（`scripts` 只有 dev/build/preview）。验证手段是：构建通过 + 页面 200 + 浏览器实际看。

### 改模型 / 接口

同步四处：`schema.sql`、`seed.sql`、`docs/api-contract.md`、`docs/数据库设计/`。

## 五、容易搞错的地方

### 5.1 权限模型

**别把这些搞反**：

- **创作作品、活动投稿对所有登录用户开放**，不限于 `CREATOR`。`CREATOR` 现在只是身份标识
- `/review/**` → `REVIEWER` / `ADMIN` / `SUPER_ADMIN`
- `/admin/**` → `ADMIN` / `SUPER_ADMIN`
- `/admin/users/**`、`/admin/settings`、`/admin/announcements` → **仅 `SUPER_ADMIN`**
- 规则靠**路径顺序**匹配，越具体的必须越靠前

### 5.2 作品的双分类

```sql
creator_work.category_id            -- 作品形态：科普图文/海报/漫画/短视频（必填，WORK 类型）
creator_work.knowledge_category_id  -- 所属学科：天文宇宙/生命科学…（选填，ARTICLE 类型）
```

后端 `validateCategory` / `validateKnowledgeCategory` 会校验类型，别混用。

### 5.3 学科主题色按名称匹配

`constants/dict.js` 里 `CATEGORY_THEME` 的键是**中文分类名**。分类改名 → 颜色回落品牌蓝。
彻底解决要给 `science_category` 加 `code` 字段，属于接口改动，还没做。

### 5.4 测试断言用增量，别用固定总数

演示数据会被手工操作污染。写断言用「按 id 判断」或「前后差值」，不要写 `total == 4` 这种。
这个坑踩过 4 次。

## 六、工具使用注意

### 6.1 改文件优先用 `edit` 工具

**不要用 PowerShell 脚本批量替换**。反复出过这些事故：

- here-string 里的 `${}` 被 PowerShell 解析
- `$k.$ext` 被当成属性访问
- `$args` 是自动变量，赋值会炸掉整条调用链
- 行号插入错位，把方法截断
- 引号被截断，生成 `|| '` 这种语法错误

改多处时用 `edit` 逐处改，慢但可靠。

### 6.2 Git 推送

远程是私有仓库 `https://github.com/lzwazb/science-platform.git`，**SSH（22 和 443）被网络阻断，只有 HTTPS 可用**。

Token 在：
```
C:\Users\z1367\.dsh\attachments\v1\files\8d\8d23d58e4e1b410cf6f99b7b252d2d9e0856f29b90cc0bea02cf7947c6aab2a8\github.txt
```

推送模板（**输出必须 mask token**）：

```powershell
$token = (Get-Content "<上面的路径>" -Raw).Trim()
$tmpRemote = "https://x-access-token:$token@github.com/lzwazb/science-platform.git"
$out = git push $tmpRemote "main:main" 2>&1
$out = $out | ForEach-Object { ($_ -replace [regex]::Escape($token), "***") }
$out | Select-Object -Last 3
```

**不要把 token 写进 `.git/config`。**

### 6.3 浏览器验证

有两个 MCP 可用：`pw`（Playwright）和 `cd`（Chrome DevTools）。

常用套路：`browser_navigate` → `browser_evaluate` 读 computed style / DOM → `browser_take_screenshot` 存图 → `read_image` 看。
