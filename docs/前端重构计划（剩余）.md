## 五、两条技术债

第一批留下的，建议在第二/三批之间顺手处理。

### 5.1 卡片组件重复

```
KnowledgeListView  →  .kb-card
HomeView           →  .article-card
WorkListView       →  .work-card
```

三套类名，样式 80% 相同。改成共享组件后：

```
components/content/ContentCard.vue    统一封面 + 标题 + 摘要 + 元信息
  props: cover, title, summary, category, meta, to
  slot:  footer（各页面自定义底部）
```

**风险**：三处样式细节不同（首页封面更大、知识库有日期、作品有作者），抽组件时要留够 slot 位。

### 5.2 学科色按名称匹配

```js
// constants/dict.js
const CATEGORY_THEME = { 天文学: {...}, 生命科学: {...} }
export function themeOf(categoryName) { return CATEGORY_THEME[categoryName] || FALLBACK }
```

后端 `science_category` 没有 `code` 字段，只能按中文名匹配。**分类改名 → 颜色回落品牌蓝**。

彻底解决要给分类表加 `code`（`ASTRONOMY` / `LIFE` / ...），属于接口改动：

1. `science_category` 加 `code VARCHAR(32)`
2. 分类 VO / DTO 带上 code
3. 前端改成按 code 匹配，名称仍用于显示

**建议**：如果论文里要写「可维护性」，这条值得做完；否则可以只写进「不足」。
