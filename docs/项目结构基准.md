# 项目结构基准

> **基准来源**：`张俊麒-开题报告.docx`（2026-10-26，指导教师：王翠）
> **提取范围**：仅「拟研究的主要内容和思路 → 主要内容」中的模块划分与角色划分。
> 报告中的选题依据、创新点、重难点、进度安排、参考文献等，**不作为**本项目基准。
> 凡功能归属、增删、命名有争议，以本文件的 A1–A7 为准。

---

## 一、基准结构：七个功能模块

| 编号 | 模块 | 结构边界（开题中的划分） |
| --- | --- | --- |
| A1 | 科普知识库与专题探索 | 知识分类、文章列表、文章详情、关键词搜索、专题内容浏览 |
| A2 | 创作者中心与作品管理 | 创作者资料维护；作品发布、分类、编辑、删除、详情展示；作品**可选择**关联已有科普文章，也可不关联 |
| A3 | 知识共建与纠错 | 提交知识补充／错误纠正／修改建议，须填理由与参考来源；记录提交人、提交时间、审核状态、处理意见；用户可查本人贡献记录 |
| A4 | 社区互动 | 文章与作品的点赞、评论、收藏及内容反馈 |
| A5 | 主题创作活动 | 管理员发布活动（说明、起止时间、参与规则）；创作者投稿；评审员人工评审；活动结束后展示优秀作品 |
| A6 | 消息通知与个人中心 | 个人资料、我的作品、我的知识贡献、我的收藏、站内消息（审核结果、评论回复、活动通知） |
| A7 | 后台管理与系统管理 | 管理员管知识分类、文章、作品、评论反馈、活动；评审员审知识贡献与作品；超级管理员管账号、角色权限、系统级配置 |

## 二、基准角色结构

| 角色 | 结构位置 |
| --- | --- |
| 普通用户 | A3 提交、A4 互动、A6 个人中心 |
| 创作者 | A2 作品、A5 投稿 |
| 内容审核（评审）人员 | A3 贡献审核、A5 活动评审、A7 审核工作台 |
| 管理员 | A7 内容与活动管理 |
| 超级管理员 | A7 账号、角色权限、系统配置 |

## 四、A2 关联规则的界定

- 关联为**可选**：作品可以关联已有科普文章，也可以不关联，两者都是合法状态。不强制、不要求关联质量。
- 当前实现：作品通过 `knowledge_category_id`（所属学科，选填）表达关联——选了学科即与该学科已发布文章产生关联，详情页按学科实时列出；不选即不关联。
- 因此「按学科自动关联」视为本基准允许的实现方式。**不**恢复 `work_article_relation` 式的文章级多选关联，除非后续明确要求。
